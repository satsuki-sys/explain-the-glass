The one sentence a house cat would say in its own defence after knocking
a glass off the table, written by a program for the
[Five Seconds to Explain the Glass](https://make.fun/c/u-po-pu-five-seconds-to-explain-the-glass-934d9949)
bounty on [make.fun](https://make.fun).

## Entry

> The glass spent all morning squatting in my sunbeam, charging rent in judgemental little glints, so I evicted it — the floor merely signed the paperwork.

One sentence, 153 characters. No apology, no confession: the glass was
squatting in the cat's sunbeam and charging rent, so the cat evicted it.

## Run

```sh
python3 main.py
```

`main.py` writes the sentence to `/output/entry.txt`.
